One-liner CSS ~30 min total · just toggle a class on <html>
Bigger Text~5 min
Scale all text by bumping root font-size.
/* Add to CSS */ html.a11y-bigger-text { font-size: 120%; } /* Toggle in JS */ html.classList.toggle('a11y-bigger-text')
Text Spacing~5 min
Increase letter, word, and line spacing per WCAG 1.4.12.
html.a11y-text-spacing * { letter-spacing: 0.12em !important; word-spacing: 0.16em !important; line-height: 1.7 !important; }
Line Height~5 min
Looser line height for easier reading.
html.a11y-line-height * { line-height: 2.0 !important; }
Text Align~5 min
Force left-align — removes justified text rivers.
html.a11y-text-align p, html.a11y-text-align li, html.a11y-text-align span { text-align: left !important; }
Pause Animations~5 min
Stop all CSS animations and transitions site-wide.
html.a11y-pause-animations *, html.a11y-pause-animations *::before, html.a11y-pause-animations *::after { animation-play-state: paused !important; transition-duration: 0ms !important; }
Hide Images~5 min
Hide all decorative images, keep alt text visible.
html.a11y-hide-images img, html.a11y-hide-images [role="img"], html.a11y-hide-images svg:not([aria-label]) { visibility: hidden !important; }
Highlight Links~5 min
Bold underline on all anchor tags to make them obvious.
html.a11y-highlight-links a { text-decoration: underline !important; text-decoration-thickness: 2px !important; text-underline-offset: 3px !important; font-weight: 600 !important; outline: 2px solid currentColor; outline-offset: 2px; }
Saturation~5 min
CSS filter — offer low/off/high as three steps.
html.a11y-sat-low body { filter: saturate(0.2) } html.a11y-sat-none body { filter: saturate(0) } html.a11y-sat-high body { filter: saturate(2.0) } /* Cycle through in JS on click */ const steps = ['', 'a11y-sat-low', 'a11y-sat-none', 'a11y-sat-high'];
Small component ~1–2 hrs each · a bit of JS state needed
Contrast +~1 hr
Override CSS variables with a high-contrast token set.
/* Override your design tokens */ html.a11y-contrast { --color-text-primary: #ffffff; --color-background-primary: #000000; --color-border-primary: #ffffff; /* Map all your tokens to HC values */ }
Cursor~1 hr
Inject a large custom cursor SVG as a fixed overlay div.
// Create a div that follows mousemove const cur = document.createElement('div'); cur.style.cssText = `position:fixed; width:32px;height:32px; background:#FFD700;border-radius:50%; pointer-events:none;z-index:99999; transform:translate(-50%,-50%)`; document.addEventListener('mousemove', e => { cur.style.left = e.clientX + 'px'; cur.style.top = e.clientY + 'px'; }); // Then: html { cursor: none !important }
Dyslexia Friendly~1 hr
Load OpenDyslexic from a CDN and apply to body text.
/* Lazy-load the font only when toggled */ function enableDyslexia() { const link = document.createElement('link'); link.rel = 'stylesheet'; link.href = 'https://fonts.cdnfonts.com' + '/css/opendyslexic'; document.head.appendChild(link); document.documentElement .classList.add('a11y-dyslexia'); } html.a11y-dyslexia body { font-family: 'OpenDyslexic' !important; }
Page Structure~2 hrs
Highlight headings and landmark regions with visible outlines.
html.a11y-structure h1, html.a11y-structure h2, html.a11y-structure h3 { outline: 2px solid #E85555 !important; } html.a11y-structure nav, html.a11y-structure main, html.a11y-structure footer, html.a11y-structure section { outline: 2px solid #3DC99A !important; } /* Add ::before labels via JS for each */
Skip for now — too complex or not applicable
Screen Reader
Not a UI feature — requires correct semantic HTML, ARIA roles, and alt text throughout the whole codebase. Foundational work, not a toggle.
Smart Contrast
Requires per-element contrast ratio calculation at runtime — computationally expensive. Use Contrast+ instead which just swaps tokens.
Tooltips
Needs every interactive element to have a title attribute and a custom tooltip renderer — a full audit of the whole codebase.
Dictionary
Requires a dictionary API, text selection detection, and a custom popup component. Non-trivial to do well and low usage for a travel app.
How to wire all of these up

Build one useAccessibility() Zustand store that holds a Set<string> of active class names. On change, sync the whole set to document.documentElement.classList and persist to localStorage. All the CSS classes above live in a single accessibility.css file imported once in main.tsx. The toggle panel becomes a simple list of buttons that call store.toggle('a11y-bigger-text') — no component needs to know about a11y logic at all.
