Typography — font pairings
  • Load Space Grotesk from Google Fonts (weights 400, 500, 600, 700) — used for all UI chrome, buttons, headings
  • Inter (var) for body copy, descriptions, metadata — superior readability at 12–14px
  • Space Mono for scores, countdowns, stats, budget numbers — unmistakably numeric identity
  • Fluid scale with clamp(): xs=10px, sm=12, base=14, lg=16, xl=20, 2xl=28, 3xl=40
  • Letter-spacing rules: headers -0.02em, mono data +0.04em, eyebrows +0.1em uppercase

  • Build an <Icon> wrapper with standardized size props (xs=14, sm=16, md=20, lg=24, xl=32)

Motion
Loading skeletons
Replace "Loading missions..." text with shimmer skeleton cards matching the exact shape of each component — kills the layout shift.
Medium
Page transitions — implementation
  • Wrap <Routes> in <AnimatePresence mode="wait"> — wait ensures exit before enter
  • Each page exports a <motion.div> as its root with variants: {enter: slide-in, exit: slide-out}
  • Direction detection: compare route depth to determine forward vs back slide direction
  • Duration: 220ms enter, 180ms exit — fast enough to feel responsive, not abrupt
  • Respect prefers-reduced-motion: use opacity-only fade as fallback
~1 dayframer-motion AnimatePresence
Micro-interactions — priority list
  • Buttons: whileTap={{ scale: 0.97 }} on all interactive buttons — 1 line per button
  • Cards: whileHover={{ y: -2 }} with shadow transition on mission/recommendation cards
  • Score counter: useSpring animating from 0 → actual score on first render of match card
  • Budget bar: Framer Motion width animation from 0% → actual% on mount (0.8s ease-out)
  • Nav active pill: layoutId shared between nav items so it slides between them
~2 daysHigh perceived quality
